# Free Company scripts

## Scripts
- [Craft Magitek Repair Materials](Craft%20Magitek%20Repair%20Materials.lua): restocks required Grade 6 Dark Matter and crafts Magitek Repair Material toward a configured total using the selected Vulcan crafting discipline.

## Requirements and setup
- Requires Vulcan, Lifestream, and vnavmesh for the crafting, travel, and restocking workflow. Configure Vulcan and ensure access to the required materials before running.
- Set the target material count and crafting discipline in SND configuration.
- Optional completion actions run a named follow-up macro or enable AutoRetainer MultiMode (requires AutoRetainer).

## Installation
Import the Lua file's GitHub URL into SND, or paste its contents into a new Lua macro.
