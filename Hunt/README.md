# Hunt scripts

## Scripts
- [Hunt Train Go To Flag](Hunt%20Train%20Go%20To%20Flag.lua): follows the current hunt flag, waits for cross-zone travel, and redirects toward the hunt mob when it loads. Stops near the hunt for dismounting and handoff.

## Requirements and setup
- Requires vnavmesh. Set a hunt map flag before running.
- Configure arrival/hunt wait distances, teleport timing estimates, and zone timeout as needed.
- Optional BossMod autorotation preset handoff requires BossMod and a valid preset name; leave it empty to disable.

## Installation
Import the Lua file's GitHub URL into SND, or paste its contents into a new Lua macro.
