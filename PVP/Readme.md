# PVP scripts

PVP centered SND lua scripts. 

## Scripts
- [Causal Match PVP](Causal%20Match%20PVP.lua)
  - Queues and requeues casual Crystalline Conflict, follows the crystal, and handles results-screen departure.
  - Supports optional Garo titles, greeting/results quickchat, a match limit, a startup gearset/Lifestream command, and a follow-up script after reaching the match limit.

## Requirements and setup
- Requires vnavmesh and RotationSolver. Optional startup travel requires Lifestream.
- Configure options before starting; a match limit of 0 repeats indefinitely.
- Startup preparation must succeed before the initial queue is issued.
- The filename remains `Causal Match PVP.lua` to preserve existing script URLs.

## Installation
- Copy script's Github URL and paste into SND GitHub URL option to import and update.
